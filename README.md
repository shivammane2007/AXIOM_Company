## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/shivammane2007/AXIOM_Company.git
cd AXIOM_Company
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

### 4. Open in browser
Navigate to [http://localhost:3000](http://localhost:3000)
